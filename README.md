# ts-bisaya++

A tree-walking interpreter for **Bisaya++**, a programming language whose keywords are written in the Cebuano/Bisaya dialect of the Philippines. Includes a web IDE for running Bisaya++ code in the browser.

## Language Features

- **Data types**: `NUMERO` (integer), `TIPIK` (float), `LETRA` (char), `TINUOD` (boolean), `STRING`
- **Variable declaration**: `MUGNA`
- **I/O**: `DAWAT:` (input), `IPAKITA:` (print)
- **Conditionals**: `KUNG … PUNDOK { }` / `KUNG DILI` / `KUNG WALA`
- **For loops**: `ALANG SA (init, condition, increment) PUNDOK { }`
- **Logical operators**: `UG` (AND), `O` (OR), `DILI` (NOT)
- **Boolean literals**: `"OO"` (true), `"DILI"` (false)
- **String concatenation**: `&`
- **Newline literal**: `$`
- **Comments**: `-- this is a comment`
- **Block delimiters**: `SUGOD` … `KATAPUSAN`

### Example

```
SUGOD
  MUGNA NUMERO x = 10, y = 3
  MUGNA TIPIK result
  result = x / y
  IPAKITA: x & " / " & y & " = " & result & $
  IPAKITA: "Maayong adlaw!"
KATAPUSAN
```

## Setup

**Prerequisites**: [Bun](https://bun.sh) and [pnpm](https://pnpm.io)

```bash
# Install root dependencies
pnpm install

# Install web frontend dependencies
cd web && pnpm install && cd ..
```

## Running

### Web IDE (recommended)

```bash
# 1. Build the frontend
pnpm web:build

# 2. Start the server (serves the UI + handles /run requests)
pnpm server
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

**For frontend development with hot reload:**

```bash
# Terminal 1 — backend
pnpm server

# Terminal 2 — Vite dev server (proxies /run to the backend)
pnpm web:dev
```

Open [http://localhost:5173](http://localhost:5173).

### CLI Script Runner

```bash
pnpm start
```

Runs the hardcoded program in `src/index.ts`. Edit that file to change the input.

### Interactive REPL

```bash
pnpm repl
```

Starts a read-eval-print loop. No `SUGOD`/`KATAPUSAN` block delimiters required in REPL mode.

## Tests

```bash
pnpm test
```

Runs the test suite using Bun's built-in test runner (`bun test`).
